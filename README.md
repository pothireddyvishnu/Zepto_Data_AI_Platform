# Zepto Data AI Platform

## Project Overview

This project contains a data-engineering pipeline that turns raw scraped data into a clean relational store, an
analytics pipeline that profiles and models a customer-style dataset end to end, and a GenAI support assistant that
answers policy questions grounded in Zepto's own documents.

## Project Structure

| Directory            | Description                                                                                                   |
|----------------------|---------------------------------------------------------------------------------------------------------------|
| `data_pipeline/`     | A data pipeline feeds Zepto's analysts clean structured data.                                                 |
| `analytics/`         | An analytics pipeline shows how Zepto would profile and predict customer/passenger-style outcomes end to end. |
| `support_assistant/` | A support assistant shows how Zepto would put a grounded GenAI service in front of its own policies.          |
